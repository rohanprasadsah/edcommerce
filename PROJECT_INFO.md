# EduInstitute - Education Course Selling Platform

## 🎓 Project Overview
A complete education website built with React + Vite for selling courses and promoting the institution.

## ✅ Installed Dependencies
- **react-router-dom** (v7.18.2) - Routing
- **lucide-react** (v1.28.0) - Icons
- **tailwindcss** (v3.4.19) - Styling
- **postcss** & **autoprefixer** - CSS processing

## 🎨 Website Structure

### Components Created:

1. **TopBar** - Advertisement strip with phone number and email
2. **Navbar** - Navigation with logo and menu items
3. **Hero** - Hero section with CTA buttons and quick stats
4. **QuoteSection** - Inspirational education quote
5. **Courses** - Course grid with 6 popular courses
6. **WhyChooseUs** - 6 feature cards explaining benefits
7. **Stats** - Statistics (10K+ students, 50+ teachers, 100+ courses, 95% success)
8. **Testimonials** - Student testimonials carousel (5 reviews)
9. **Faculty** - Expert faculty showcase with 4 instructors
10. **Footer** - Complete footer with recognized by section, links, and contact info

### Features:
✅ Top advertisement strip with contact info
✅ Responsive navigation bar
✅ Hero section with illustrations and CTAs
✅ Inspirational quotes section
✅ 6 popular courses display
✅ Testimonials carousel (auto-rotating)
✅ Why Choose Us section
✅ Stats display (students, teachers, courses, success rate)
✅ Faculty showcase
✅ "Recognized By" section (Ministry of Education, ISO, NAAC, AICTE)
✅ Complete footer with social links

## 🚀 Commands

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
```
